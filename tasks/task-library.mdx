## What is the Task Library?

The **Task Library** is a curated collection of ready-to-use EEG processing pipelines maintained by the AutoCleanEEG team. Think of it as a cookbook of validated recipes for common EEG paradigms—resting state, event-related potentials, auditory protocols, and more.

<Note>
**Key Benefits:**
- 📦 **Pre-configured**: All parameters optimized for each paradigm
- ✅ **Validated**: Tested on real data across multiple labs
- 🔄 **Updated**: Regular updates with improvements and bug fixes
- 🆓 **Free**: Open-source and freely available to all users
</Note>

## Browsing the Library

### See All Available Tasks

View all tasks in the library:

```bash
autocleaneeg-pipeline task list --source=library
```

### Search for Specific Tasks

Find tasks by keyword:

```bash
# Find all resting-state tasks
autocleaneeg-pipeline task search resting

# Find auditory tasks
autocleaneeg-pipeline task search auditory

# Find mouse/rodent tasks
autocleaneeg-pipeline task search mouse
```

<Tip>
**Search is smart!** It looks through task names AND descriptions, so you can search by paradigm, method, or species.
</Tip>

## Task Categories

The library is organized into categories based on experimental paradigm:

<AccordionGroup>
<Accordion title="🧘 Resting State" icon="brain">
**For spontaneous EEG recordings without tasks**

Ideal for: Baseline recordings, developmental studies, clinical assessments

**Available Tasks:**
- `RestingEyesOpen` - Standard eyes-open resting state
- `RestingEyesClosed` - Standard eyes-closed resting state
- `BiotrialResting1020` - 10-20 system resting protocol

**Key Features:**
- Continuous data processing
- Optimal for spectral power analysis
- Artifact removal tuned for resting data
- Automated bad channel detection

**Typical Use Cases:**
- Developmental EEG (infants, children, adults)
- Clinical populations (ADHD, autism, epilepsy)
- Neurofeedback baseline assessments
- Pharmaco-EEG studies
</Accordion>

<Accordion title="🎵 Auditory Protocols" icon="volume">
**For sound-based stimulus paradigms**

Ideal for: ASSR, chirp, MMN, auditory evoked potentials

**Available Tasks:**
- `ASSR_40Hz` - 40Hz auditory steady-state response
- `Chirp_Default` - Frequency-modulated auditory stimulus
- `MMN_Standard` - Mismatch negativity (oddball)
- `BB_Long` - Long-duration broadband stimulation

**Key Features:**
- Event-triggered epoching
- Optimized filtering for auditory frequencies
- Automatic peak detection
- Stimulus-locked averaging

**Typical Use Cases:**
- Hearing research
- Auditory development studies
- Clinical hearing assessments
- Frequency-specific responses
</Accordion>

<Accordion title="👁️ Visual Protocols" icon="eye">
**For visual stimulus paradigms**

Ideal for: VEP, visual oddball, flash stimuli

**Available Tasks:**
- `HBCD_VEP` - HBCD study visual evoked potentials
- `VEP_Standard` - Standard VEP protocol

**Key Features:**
- Visual artifact handling
- Flash-locked averaging
- Occipital channel focus
- Pattern reversal optimization

**Typical Use Cases:**
- Visual system development
- Clinical vision assessments
- Cognitive paradigms with visual stimuli
- Attent

ion and perception studies
</Accordion>

<Accordion title="🐭 Rodent EEG" icon="dna">
**For mouse and rat EEG recordings**

Ideal for: Preclinical research, animal models

**Available Tasks:**
- `Mouse_XDAT_ASSR` - Mouse ASSR with correlation-based rejection
- `Mouse_XDAT_Resting` - Mouse resting-state
- `Mouse_XDAT_Chirp` - Mouse chirp protocol

**Key Features:**
- Species-specific montages
- Correlation-based artifact removal
- High-frequency optimization
- Animal model best practices

**Typical Use Cases:**
- Preclinical drug studies
- Animal models of neurological conditions
- Developmental neuroscience (rodent)
- Comparative neuroscience
</Accordion>
</AccordionGroup>

## Installing Tasks from the Library

### One-Step Install (Recommended)

The fastest way to start using a library task:

```bash
autocleaneeg-pipeline task use ASSR_40Hz
```

This command:
1. ✅ Downloads the task from the library
2. ✅ Installs it to your workspace
3. ✅ Sets it as your active task
4. ✅ You're ready to process data immediately!

<CodeGroup>
```bash Example Output
✓ ASSR_40Hz installed to /Users/you/Autoclean-EEG/tasks/ASSR_40Hz.py
✓ Active task set to: ASSR_40Hz
Ready to process: autocleaneeg-pipeline process <file>
```
</CodeGroup>

### Install Without Activating

Want to install a task but not activate it yet?

```bash
autocleaneeg-pipeline task install MMN_Standard
```

Then activate it later:

```bash
autocleaneeg-pipeline task set MMN_Standard
```

### Install with Custom Name

Install a task with a different name (useful for variants):

```bash
autocleaneeg-pipeline task install ASSR_40Hz --name ASSR_Modified
```

<Info>
**Why custom names?**
- Create multiple variants of the same task
- Compare different parameter sets
- Keep original and modified versions separate
</Info>

## Understanding Task Status

When you list tasks, you'll see status indicators:

### Status Icons Explained

| Icon | Status | Meaning |
|------|--------|---------|
| ✓ | **Synced** | Your workspace copy matches the library exactly |
| ⚠ | **Customized** | You've modified this task locally |
| ↻ | **Outdated** | A newer version is available in the library |
| ✗ | **Orphaned** | Task was removed from the library |
| 📦 | **Available** | Ready to install from the library |

## Keeping Tasks Up to Date

### Check for Library Updates

See if new tasks or updates are available:

```bash
autocleaneeg-pipeline task update
```

This updates your local index of the task library from GitHub.

<CodeGroup>
```bash Example Output
→ Updating task library from GitHub registry...

✓ Found 3 change(s) in library

 Task          Change
 ASSR_40Hz     updated
 NewMMN_Task   new
 Old_Task      removed

New tasks available:
  • Run 'task list --source=library' to see all library tasks
  • Run 'task use <name>' to install and activate a new task

Tasks with updates:
  • Run 'task sync' to check if your workspace tasks are outdated
  • Run 'task sync --update' to automatically update outdated tasks
```

<Tip>
**Run this monthly!** We regularly update tasks with improvements, bug fixes, and new features.

### Auto-Update Tasks

Apply updates automatically (with backup):

```bash
autocleaneeg-pipeline task sync --update
```

<Warning>
**Customized tasks**: If you've modified a task, `sync --update` will:
1. Create a backup (e.g., `RestingState.backup.2025-09-29.py`)
2. Install the new version from the library
3. You'll need to manually re-apply your customizations if desired
</Warning>

## Best Practices

### ✅ DO:

<Steps>
<Step title="Start with Library Tasks">
Always check the library first before creating custom tasks. Most common paradigms are already available.
</Step>

<Step title="Update Regularly">
Run `task update` monthly to get improvements and new features.
</Step>

<Step title="Use Descriptive Names">
When installing with custom names, use clear, descriptive names: `ASSR_HighFreq`, `Resting_LongDuration`
</Step>

<Step title="Check Sync Status">
Before big processing runs, check `task sync` to ensure you're using the latest versions.
</Step>
</Steps>

### ❌ DON'T:

<Warning>
- **Don't edit library tasks directly**: Always install first, then customize
- **Don't ignore outdated warnings**: Updates often include important bug fixes
- **Don't forget to backup**: If you customize a task, keep a backup before updating
- **Don't mix versions**: If working with collaborators, ensure everyone uses the same task version
</Warning>

## Troubleshooting

<AccordionGroup>
<Accordion title="Task not found in library" icon="magnifying-glass">
**Problem**: `task use TaskName` says task not found

**Solutions**:
1. Update the library index: `task update`
2. Check spelling: `task list --source=library`
3. Search for similar names: `task search TaskName`
4. Task might have been renamed or removed (check release notes)
</Accordion>

<Accordion title="Can't update - customized task" icon="triangle-exclamation">
**Problem**: `task sync --update` warns about customized tasks

**Solutions**:
1. Preview changes: `task diff TaskName`
2. Backup your version: Copy the file manually or use the auto-backup feature
3. Update and re-apply customizations: `task sync --update` then `task edit TaskName`
4. Keep your version: Don't update if your customizations are critical
</Accordion>

<Accordion title="Library tasks missing after update" icon="wifi-slash">
**Problem**: Network issues or cache problems

**Solutions**:
```bash
# Force refresh the library
task update

# Check library health
task diagnose

# View cache status
task list  # Shows cache age and status
```
</Accordion>

<Accordion title="How to contribute to the library?" icon="code-pull-request">

</Accordion>
