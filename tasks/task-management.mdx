## Discovery & Browsing

### `task list`

Display all available tasks with filtering options.

**Syntax:**
```bash
autocleaneeg-pipeline task list [OPTIONS]
```

**Options:**

| Option | Values | Description |
|--------|--------|-------------|
| `--source` | `all`, `library`, `builtin`, `workspace`, `active` | Filter by task source |
| `--status` | `all`, `installed`, `available`, `outdated`, `customized` | Filter by installation status |
| `--category` | `all`, `resting`, `auditory`, `visual`, `rodent` | Filter by paradigm category |
| `--format` | `table`, `json` | Output format |
| `--overrides` | (flag) | Show workspace tasks overriding built-ins |

**Examples:**

<CodeGroup>
```bash Show All Tasks
autocleaneeg-pipeline task list
```

```bash Library Tasks Only
autocleaneeg-pipeline task list --source=library
```

```bash Installed Tasks
autocleaneeg-pipeline task list --status=installed
```

```bash Resting State Tasks
autocleaneeg-pipeline task list --category=resting
```

```bash JSON Output
autocleaneeg-pipeline task list --format=json
```

```bash Override Detection
autocleaneeg-pipeline task list --overrides
```
</CodeGroup>

**Output:**

## Installation & Setup

### `task use` ⭐

**One-step install and activate** - The simplest way to start using a task.

**Syntax:**
```bash
autocleaneeg-pipeline task use [task_name] [OPTIONS]
```

**Arguments:**
- `[task_name]` - Task to install (omit for interactive selection)

**Options:**

| Option | Description |
|--------|-------------|
| `--force` | Overwrite existing workspace copy |
| `--no-activate` | Install only, don't set as active |

**Examples:**

<CodeGroup>
```bash Install and Activate
autocleaneeg-pipeline task use ASSR_40Hz
```

```bash Interactive Selection
autocleaneeg-pipeline task use
# Shows numbered list to choose from
```

```bash Install Without Activating
autocleaneeg-pipeline task use MMN_Standard --no-activate
```

```bash Force Overwrite
autocleaneeg-pipeline task use RestingState --force
```
</CodeGroup>

**Output:**
```
✓ ASSR_40Hz installed to /Users/you/Autoclean-EEG/tasks/ASSR_40Hz.py
✓ Active task set to: ASSR_40Hz
Ready to process: autocleaneeg-pipeline process <file>
```

<Tip>
**Recommended for most users!** `task use` combines installation and activation in one command.
</Tip>

---

### `task install`

Universal installer supporting multiple sources (library, file, built-in).

**Syntax:**
```bash
autocleaneeg-pipeline task install <source> [OPTIONS]
```

**Arguments:**
- `<source>` - Task name (library/builtin) or file path

**Options:**

| Option | Values | Description |
|--------|--------|-------------|
| `--source` | `auto`, `library`, `file`, `builtin` | Explicitly specify source type |
| `--name` | `<custom_name>` | Install with a different name |
| `--force` | (flag) | Overwrite existing task |
| `--activate` | (flag) | Set as active after installing |

**Examples:**

<CodeGroup>
```bash From Library
autocleaneeg-pipeline task install ASSR_40Hz
```

```bash From File
autocleaneeg-pipeline task install /path/to/custom_task.py
```

```bash With Custom Name
autocleaneeg-pipeline task install ASSR_40Hz --name ASSR_Modified
```

```bash Install and Activate
autocleaneeg-pipeline task install Chirp_Default --activate
```

```bash From File with Custom Name
autocleaneeg-pipeline task install my_task.py --name ProjectX_Task
```
</CodeGroup>

**Auto-Detection:**

The `install` command automatically detects the source:
- **File path exists** → Installs from file
- **Name in library** → Installs from library
- **Name in built-ins** → Installs from built-in tasks

<CodeGroup>


**Output:**
```

```

---

### `task unset`

Clear the active task selection.

**Syntax:**
```bash
autocleaneeg-pipeline task unset
```

**Example:**
```bash
autocleaneeg-pipeline task unset
```

**Output:**
```
✓ Active task cleared
```

<Note>
After unsetting, you'll need to specify a task when running `process` or set a new active task.
</Note>

## Maintenance & Updates

### `task update`

Update the task library index from GitHub registry.

**Syntax:**
```bash
autocleaneeg-pipeline task update [OPTIONS]
```

**Options:**

| Option | Description |
|--------|-------------|
| `--no-network` | Skip network check, use cache only |

**Examples:**

<CodeGroup>
```bash Update Library
autocleaneeg-pipeline task update
```

```bash Offline Mode
autocleaneeg-pipeline task update --no-network
```
</CodeGroup>

**Output:**
```
→ Updating task library from GitHub registry...

✓ Found 3 change(s) in library

 Task          Change
 ASSR_40Hz     updated
 NewTask       new
 OldTask       removed

New tasks available:
  • Run 'task list --source=library' to see all library tasks
  • Run 'task use <name>' to install and activate a new task

Tasks with updates:
  • Run 'task sync' to check if your workspace tasks are outdated
  • Run 'task sync --update' to automatically update outdated tasks
```

<Tip>
**Run monthly** to get the latest task improvements and new features!
</Tip>

### `task sync`

Check workspace tasks for updates and optionally apply them.

**Syntax:**
```bash
autocleaneeg-pipeline task sync [OPTIONS]
```

**Options:**

| Option | Description |
|--------|-------------|
| `--update` | Automatically apply updates (creates backups) |
| `--dry-run` | Show what would be updated without making changes |

**Examples:**

<CodeGroup>
```bash Check Status
autocleaneeg-pipeline task sync
```

```bash Auto-Update
autocleaneeg-pipeline task sync --update
```

```bash Preview Changes
autocleaneeg-pipeline task sync --dry-run
```
</CodeGroup>

**Output:**
```
→ Checking workspace tasks against sources...

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
 SYNC STATUS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

 ✓  ASSR_40Hz          [library]  up to date
 ⚠  RestingState       [library]  customized
 ↻  MMN_Standard       [library]  outdated
 ✗  OldTask            [orphan]   source removed

Summary:
  • 1 task has updates available
  • 1 customized task
```

- ✓ **Synced** - Workspace matches library exactly

### `task diff`

Show differences between workspace task and its source.

**Syntax:**
```bash
autocleaneeg-pipeline task diff <task_name> [OPTIONS]
```

**Arguments:**
- `<task_name>` - Task to compare

**Options:**

| Option | Description |
|--------|-------------|
| `--color` | Enable colored diff output (default: auto) |
| `--context` | Number of context lines (default: 3) |

**Examples:**

<CodeGroup>
```bash Compare Task
autocleaneeg-pipeline task diff MMN_Standard
```

```bash More Context
autocleaneeg-pipeline task diff MMN_Standard --context=5
```
</CodeGroup>

**Output (if no changes):**
```
✓ No differences - workspace copy matches library
```

**Output (with changes):**
```diff
--- Workspace: MMN_Standard.py
+++ Library: MMN_Standard.py

@@ -45,7 +45,7 @@
     "filtering": {
         "enabled": True,
         "value": {
-            "l_freq": 0.5,
+            "l_freq": 0.1,  # Improved low-frequency filtering
             "h_freq": 100,
             "notch_freqs": [60, 120]
         }
```

## Workspace Management

### `task delete`

Remove a task file from your workspace.

**Syntax:**
```bash
autocleaneeg-pipeline task delete [task_name]
```

**Arguments:**
- `[task_name]` - Task to delete (omit to delete active task)

**Examples:**

<CodeGroup>
```bash Delete Specific Task
autocleaneeg-pipeline task delete OldTask
```

```bash Delete Active Task
autocleaneeg-pipeline task delete
```
</CodeGroup>

**Output:**
```
⚠ This will permanently delete: OldTask
Continue? [y/N]: y
✓ Task deleted: OldTask.py
```

<Warning>
**Built-in tasks are protected** - You can only delete tasks in your workspace. Built-in tasks cannot be deleted.
</Warning>

---

### `task edit`

Open a task file in your editor for modification.

**Syntax:**
```bash
autocleaneeg-pipeline task edit [task_name]
```

**Arguments:**
- `[task_name]` - Task to edit (omit for active task)

**Examples:**

<CodeGroup>
```bash Edit Active Task
autocleaneeg-pipeline task edit
```

```bash Edit Specific Task
autocleaneeg-pipeline task edit ASSR_40Hz
```
</CodeGroup>

**Behavior:**
- Opens task file in your default editor (`$EDITOR`)
- Creates workspace copy if editing a built-in task
- Validates file after saving

**Editor Priority:**
1. `$EDITOR` environment variable
2. `$VISUAL` environment variable
3. Platform defaults (nano, vim, notepad)

---

### `task explore`

Open the tasks folder in your file browser.

**Syntax:**
```bash
autocleaneeg-pipeline task explore
```

**Example:**
```bash
autocleaneeg-pipeline task explore
```

**Behavior:**
- **Mac**: Opens in Finder
- **Linux**: Opens in default file manager
- **Windows**: Opens in Explorer

**Opens:** `~/Documents/Autoclean-EEG/tasks/`

### `task copy`

Copy an existing task to create a new customizable variant.

**Syntax:**
```bash
autocleaneeg-pipeline task copy [source] [destination]
```

**Arguments:**
- `[source]` - Task to copy from (omit for interactive selection)
- `[destination]` - New task name

**Examples:**

<CodeGroup>
```bash Copy Task
autocleaneeg-pipeline task copy RestingState MyRestingVariant
```

```bash Interactive Copy
autocleaneeg-pipeline task copy
# Shows list of tasks to copy from
# Prompts for new name
```
</CodeGroup>

**Output:**
```
✓ Task copied: RestingState → MyRestingVariant
📁 Location: /Users/you/Autoclean-EEG/tasks/MyRestingVariant.py
```

## Advanced Features

### `task import` (Legacy)

Import an external task file into workspace.

**Deprecated**: Use `task install <file>` instead for unified installation.

This command will show a deprecation warning but continues to work for backward compatibility.
</Warning>

**Syntax:**
```bash
autocleaneeg-pipeline task import <path> [OPTIONS]
```

**Options:**

| Option | Description |
|--------|-------------|

| `--force` | Overwrite existing task |

### `task add` (Legacy)

Add a custom task file to workspace.

<Warning>
**Deprecated**: Use `task install <file>` instead for unified installation.

This command will show a deprecation warning but continues to work for backward compatibility.
</Warning>

**Syntax:**
```bash
autocleaneeg-pipeline task add <file> [OPTIONS]
```

---

### `task library` (Legacy)

Access library management commands (old namespace).

<Warning>
**Modernized Commands:**
- `task library update` → `task update`
- `task library install` → `task use` or `task install`
- `task library list` → `task list --source=library`

The old commands still work but show deprecation warnings.
</Warning>

**Old Syntax:**
```bash
autocleaneeg-pipeline task library <action>
```

**Actions:**
- `update` - Update library (use `task update` instead)
- `list` - List library tasks (use `task list --source=library` instead)
- `install` - Install from library (use `task use` or `task install` instead)

## Environment Variables

### `EDITOR`

Set your preferred text editor for `task edit`:

```bash
# Bash/Zsh
export EDITOR=nano
export EDITOR=vim
export EDITOR=code  # VS Code

# Use in current session
EDITOR=nano autocleaneeg-pipeline task edit
```

### `AUTOCLEAN_WORKSPACE`

Override default workspace location:

```bash
export AUTOCLEAN_WORKSPACE=/custom/path/to/workspace
```

## Exit Codes

All task commands return standard exit codes:

| Code | Meaning |
|------|---------|
| `0` | Success |
| `1` | General error |
| `2` | Invalid arguments |

**Example usage in scripts:**
```bash
if autocleaneeg-pipeline task use ASSR_40Hz; then
    echo "Task activated successfully"
    autocleaneeg-pipeline process data.raw
else
    echo "Failed to activate task"
    exit 1
fi
```
