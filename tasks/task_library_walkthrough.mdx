Learn how to keep your Task Library current and bring new templates into your workspace.

<Tip>
The CLI now uses `task library` (replacing the old `task builtins` name). The legacy commands still work but print a gentle reminder.
</Tip>

## 1. Refresh the library index

Make sure you have the newest list of templates. This only contacts GitHub for a tiny JSON file.

```bash
autocleaneeg-pipeline task library update
```

- **If you're offline:** add `--no-network` to skip the online check; the CLI will use the cached snapshot bundled with the app.
- **Timeouts:** the command returns quickly even on locked-down networks. Any issue is recorded and reported the next time you open `task library`.

## 2. Browse available templates

```bash
autocleaneeg-pipeline task library list --show-paths
```

What you will see:

- **Status badge** — `up to date`, `customized`, `install to use`, or `status unknown`.
- **Source** — `local download` (from GitHub), `bundled snapshot` (shipped with the app), or `missing` if the template couldn't be located.
- Add `--refresh` if you want to combine steps 1 and 2 in a single command.

## 3. Install a template into your workspace

```bash
autocleaneeg-pipeline task library install RestingEyesQuickCheck
```

- The file is copied to your workspace `tasks/` folder so you can edit it safely.
- Use `--force` to overwrite an existing copy (handy when you want to compare to the latest official version).

After installing, run `task library list` again to confirm the status flips to `up to date` and the source shows `local download`.

## 4. Customize and use the task

Open the new file from your workspace and tailor it:

```bash
autocleaneeg-pipeline task edit RestingEyesQuickCheck
```

Set it as the active task if you want to run the pipeline immediately:

```bash
autocleaneeg-pipeline task set RestingEyesQuickCheck
```

## Troubleshooting

- **Template missing?** Run `task library list --refresh` to clear the GitHub cache, then list again.
- **Offline environments?** The CLI automatically falls back to the bundled snapshot; the banner shows "Working offline" along with the timestamp of the last successful check.
- **Legacy commands?** `task builtins` commands still exist but map directly to `task library`. Update scripts when convenient.
