## Workspace: Your Processing Hub

The workspace is a folder that contains all your EEG processing work: task files, results, and logs. AutoCleanEEG creates it automatically at `~/Documents/Autoclean-EEG/` when you first run the pipeline.

## Automatic Setup

No configuration needed. Just run AutoCleanEEG and your workspace is created with the right structure:

```
Autoclean-EEG/
├── tasks/           # Your task files
├── output/          # All processing results
└── logs/            # Execution logs
```

## Three Simple Parts

**tasks/** - Python files defining your preprocessing pipelines. Drop a `.py` task file here and it's immediately available.

**output/** - Every time you process data, results are saved in a folder named after your task. Rerunning automatically creates backups so nothing is ever lost.

**logs/** - System execution logs for troubleshooting.

## Quick Access

```bash
# Open workspace in file explorer
autocleaneeg-pipeline workspace explore

# Show workspace location and disk space
autocleaneeg-pipeline workspace show
```
