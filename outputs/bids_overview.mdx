# The `bids/` Folder

Each pipeline run outputs results in **BIDS (Brain Imaging Data Structure)** format, a widely adopted standard for EEG and neuroimaging data. This ensures your cleaned data are interoperable with other tools (e.g., EEGLAB-BIDS, MNE-BIDS, BIDS Validator).

The `bids/` subfolder contains:

* **Cleaned continuous and epoched EEG data** in BIDS layout
* **Standard metadata files** describing participants, dataset structure, and channels
* Events and derivatives for reproducibility

<Tip>
Because BIDS enforces strict formatting rules, the **subject identifier (`sub-XXXX`)** inside the `bids/` folder will not necessarily match the original filename.  
To see how subjects are linked to original recordings, check the **`participants.tsv`** file, which maps subject IDs to participant metadata.
</Tip>

```
output/bids/
├── dataset_description.json      # Dataset metadata
├── participants.tsv              # Subject list with demographics
├── participants.json             # Column descriptions for participants.tsv
├── README                        # Dataset documentation
├── sub-001/                      # Subject folders
│   ├── eeg/                      # EEG data in BIDS format
│   └── sub-001_scans.tsv         # Scan inventory
├── sub-002/
│   ├── eeg/
│   └── sub-002_scans.tsv
└── derivatives/                  # Step-by-step processing outputs
    ├── 01_import/
    ├── 02_resample/
    └── ... (15 processing steps)
```

## What's Inside

### Dataset Files

| File | What It Contains |
|------|------------------|
| **dataset_description.json** | Dataset name, pipeline version, BIDS specification |
| **participants.tsv** | List of subjects with demographics (age, sex, group) |
| **participants.json** | Describes what each column in participants.tsv means |
| **README** | Free-text description of your study and dataset |

These files make your data machine-readable and ensure compatibility with BIDS tools.

### Subject Folders

Each subject gets a folder (`sub-001/`, `sub-002/`, etc.) containing:
- **eeg/** - EEG data files in BIDS format (.vhdr, .eeg, .vmrk for BrainVision format)
- **Sidecar JSON files** - Metadata about channels, coordinates, events
- **scans.tsv** - Inventory linking BIDS files to original source files

The subject ID might not match your original filename—check `participants.tsv` or the subject's `scans.tsv` to see the mapping.

### Derivatives Folder

The `derivatives/` folder contains numbered subfolders (01_import, 02_resample, etc.) showing your data after each processing step. See [Derivatives Overview](/outputs/derivatives_overview) for complete details.

## BIDS Format Benefits

**Tool Compatibility:** Works with MNE-Python, EEGLAB, FieldTrip, fMRIPrep, and hundreds of other tools

**Data Sharing:** Other researchers can immediately understand and use your data

**Validation:** Run the [BIDS Validator](https://bids-standard.github.io/bids-validator/) to check correctness

**Long-term Storage:** Standard format means data remains accessible as tools evolve

## Loading BIDS Data

**MNE-Python:**
```python
from mne_bids import read_raw_bids
bids_path = BIDSPath(subject='001', task='restingstate',
                      root='output/bids')
raw = read_raw_bids(bids_path)
```

**EEGLAB:** Use the BIDS-EEG-EEGLAB plugin

**FieldTrip:** Use `ft_read_header` and `ft_read_data` on BIDS paths

## Quick Access Alternative

Don't want to deal with BIDS structure? The `exports/` folder (at the output root level) contains the same final cleaned data in a simple flat structure for immediate analysis. See [Exports Overview](/outputs/final_files) for details.
