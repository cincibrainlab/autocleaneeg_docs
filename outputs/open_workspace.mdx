## Open Workspace Folder

The fastest way to open your workspace in your file explorer:

```bash
autocleaneeg-pipeline workspace explore
```

This opens your workspace directory in:
- **macOS** - Finder
- **Linux** - Your default file manager
- **Windows** - File Explorer

## Check Workspace Location

```bash
autocleaneeg-pipeline workspace show
```

Shows the current workspace path and disk space available.

## Default Location

By default, your workspace is at:
```
~/Documents/Autoclean-EEG/
```

## Change Workspace Location

```bash
autocleaneeg-pipeline workspace set /path/to/new/location
```

Useful for:
- Moving to external drive with more space
- Separate workspaces for different projects
- Network storage for team access

## What's in the Workspace?

Your workspace contains three main areas:

| Folder | Contents |
|--------|----------|
| **tasks/** | Your preprocessing task files (.py) |
| **output/** | All processing results, organized by task |
| **logs/** | System execution logs |

For a complete understanding of the workspace structure, see [Workspace Overview](/workspace-overview).

To understand what the pipeline produces, see [Pipeline Outputs](/outputs/outputs_overview).
