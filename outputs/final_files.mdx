## The `exports/` Folder

The `exports/` folder contains your final cleaned data in a format you can immediately load into analysis scripts. No need to navigate nested BIDS directories—grab these files and start analyzing.

```
exports/
├── recording1_comp_epo.set           # Cleaned epochs (EEGLAB)
├── recording1_processing_log.csv     # Processing record
├── recording2_comp_epo.set           # Another file
└── recording2_processing_log.csv     # Its processing log
```

For each recording, you get:
* **`*_comp_epo.set`** - Final cleaned, epoched EEG data (EEGLAB format)
* **`*_processing_log.csv`** - Complete processing record (filters, bad channels, ICA, etc.)

## File Format: EEGLAB

The `.set` files work with all major EEG tools:

**EEGLAB (MATLAB):**
```matlab
EEG = pop_loadset('recording1_comp_epo.set');
```

**MNE-Python:**
```python
epochs = mne.io.read_epochs_eeglab('recording1_comp_epo.set')
```

**FieldTrip, BrainVision Analyzer, and most EEG software** also support EEGLAB format.

## What's in the Processing Log

Each `.csv` file records exactly what was done to that recording:
- Filter settings (high-pass, low-pass, notch frequencies)
- Bad channels identified and removed
- ICA components removed
- Epochs created and rejected
- Data quality metrics

Open it in Excel, Python (pandas), or R to review processing details or generate quality reports.

## File Naming

`recording1_comp_epo.set`:
- **comp** = "compiled/complete" - final processed data
- **epo** = "epochs" - segmented time windows

This naming clearly identifies files as final, analysis-ready outputs.

## Quick Analysis Examples

**Python (MNE):**
```python
import mne
epochs = mne.io.read_epochs_eeglab('recording1_comp_epo.set')
evoked = epochs.average()
evoked.plot()
```

**MATLAB (EEGLAB):**
```matlab
EEG = pop_loadset('recording1_comp_epo.set');
figure; plot(mean(EEG.data, 3));
```

## Relationship to BIDS Structure

The same cleaned data exists in multiple places:
- **exports/** - Quick access (here)
- **bids/derivatives/15_comp/** - Full processing chain
- **bids/sub-*/eeg/** - BIDS-formatted version

Use whichever is most convenient:
- **exports/** for fast analysis
- **bids/** for BIDS tools or data sharing
